# نرم‌افزار دفتر خروج کالا

سیستم مدیریت مجوز خروج کالا برای گمرکات و واحدهای صنعتی — ثبت مجوز، کنترل سهمیه گواهی‌های تولید، مدیریت بدهی، گزارش‌های رسمی PDF و نمودارهای تحلیلی.

![نسخه](https://img.shields.io/badge/نسخه-1.3.0-4F46E5) ![پایتون](https://img.shields.io/badge/Python-3.10+-3776AB) ![Qt](https://img.shields.io/badge/PyQt6-6.11-41CD52)

## ✨ قابلیت‌ها

### عملیاتی
- **ثبت مجوز خروج** با شماره‌گذاری خودکار سالانه (۱۴۰۵/۰۰۱) و چاپ روبرگه «خروج بلامانع»
- **گواهی‌های تولید** با کنترل سهمیه، کسر خودکار، **تاریخ انقضا** و هشدار نزدیک‌به‌انقضا
- **مدیریت بدهی** — خروجِ بیش از سهمیه به‌عنوان بدهی ثبت و با گواهی بعدی تسویه می‌شود
- **اسکن نامه‌ها** با WIA و پیوست به مجوز + مشاهده‌گر تصاویر
- **ثبت مشابه** — فرم جدید با الگوی مجوز قبلی (برای مرجوعی‌های تکراری)
- **تسویه گروهی بدهی‌ها** در یک تراکنش اتمیک

### تحلیل و گزارش
- **۳ نمودار**: خروج ماهانه، سهم شرکت‌ها، روند بدهی + خروجی PNG
- **۵ گزارش PDF رسمی** با سربرگ سازمانی: دوره‌ای، ریز مصرف، صورتحساب شرکت، مانیفست روزانه، روبرگه
- **خروجی Excel** از نتایج جستجو
- **پیش‌بینی اتمام گواهی** بر اساس میانگین مصرف ماهانه
- **جستجوی پیشرفته**: شرکت، شماره ثبت، کالا، مقصد، نماینده گمرک، بازه تاریخ

### امنیت و پایداری داده
- **پشتیبان‌گیری خودکار روزانه** + **پشتیبان دوم هفتگی** به فلش/درایو شبکه
- **رمز ورود اختیاری** با هش PBKDF2-SHA256 (۵ تلاش، قفل پس از شکست)
- **مهاجرت‌های نسخه‌دار دیتابیس** — ارتقای ساختار با پشتیبان خودکار و بدون دست‌کاری دستی
- **گارد تک‌نمونه** — جلوگیری از خرابی شماره‌گذاری با اجرای هم‌زمان
- **Zip-Slip ایمن** در بازگردانی پشتیبان

### ظاهر (نسخه ۱.۳.۰)
- **فونت وزیرمتن** باندل‌شده + **حالت تیره** با اعمال فوری
- **اسپلش‌اسکرین**، پیام‌های Toast، ترنزیشن نرم بین صفحات
- **جداکننده هزارگان فارسی** (۳٬۵۰۰٬۰۰۰)، نشان رنگی وضعیت بدهی، حالت خالی جداول
- **میان‌برهای F1-F9** + یادآوری چیدمان پنجره + ردیف اقدام سریع

## 🚀 اجرا از سورس

```bash
# ۱. محیط مجازی
python -m venv .venv
.venv\Scripts\activate        # ویندوز

# ۲. وابستگی‌ها
pip install -r requirements.txt

# ۳. اجرا
python main.py
```

پایگاه داده SQLite به‌صورت خودکار در `data/sabtedaftar.db` ساخته و مهاجرت‌ها اعمال می‌شوند.

## 📦 ساخت EXE و نصاب

```bash
build.bat
```

خروجی: `dist\DafterKhorojKala.exe` (تک‌فایل مستقل، ~۵۱MB) + نصاب Inno Setup اگر نصب باشد.
